## Notes

- **`script/setup`** wraps `bun install` via `script/lib/common.sh`. In some agent
  shell environments, bash `pwd` returns a duplicated path and `script/*` fails.
  Workaround: run `bun install` directly, or use `./script/cibuild` from a normal
  terminal (verified PASS on feature branch).
- **Cherri optional:** machines without `cherri` on PATH should set
  `POLYCAST_SKIP_CHERRI=1` for build (CI sets this automatically). Shortcuts
  emitter still writes `.cherri` source.
- README quickstart uses `script/setup` — acceptable when run from a standard
  terminal; Development section documents `POLYCAST_SKIP_CHERRI`.
