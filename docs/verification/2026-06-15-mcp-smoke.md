# MCP smoke verification

Level **B** behavioral proof that the stdio MCP server exposes working tools.

## Automated (CI)

`test/mcp-smoke.test.ts` spawns `bun run src/mcp/server.ts`, connects an MCP
client, and calls `polycast_targets`. Expects JSON array with `raycast-script`.

```sh
bun test test/mcp-smoke.test.ts
```

## Manual (Cursor)

1. Add MCP server config (see README MCP section).
2. Restart Cursor / reload MCP.
3. Ask the agent to call `polycast_list` — should return `uppercase`, `open-repo`, etc.
4. Call `polycast_build` with `strict: true` — should return `written` > 0.

## Expected tools

`polycast_list`, `polycast_targets`, `polycast_build`, `polycast_apply`,
`polycast_prune`, `polycast_run`, `polycast_command_upsert`
