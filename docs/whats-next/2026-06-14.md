# What's Next — 2026-06-14

**Strategic track:** `finish`

**Project goal / north star:**

polycast is a macOS transcompiler: one `CommandDef` (metadata + script body + I/O modality) renders into Raycast, PopClip, Dropzone, Dropover, Shortcuts, and agent CLI artifacts. The operator writes a command once in `commands/*.ts` and casts it everywhere compatible surfaces allow. README (`README.md`) still labels the project an "Early skeleton," but local WIP implements eight emitters, `build --strict`, and `apply`. Main (`deed24a`) only ships two emitters — the launchable product is ahead of what is merged.

## Product Strategy

- **Target Persona:** macOS operator maintaining personal automation across Raycast, PopClip, Dropzone, Shortcuts, and agent tools — comfortable with bun, dotfiles-style install paths, and launcher-specific quirks.
- **Job To Be Done:** Stop duplicating the same verb logic across launcher formats; edit one canonical definition and regenerate every surface.
- **Core Value Path:** Author `CommandDef` in `commands/` → `polycast build` → `polycast apply --write` → run command in Raycast / PopClip / Dropzone / agent-cli.
- **Activation Moment:** Operator selects text or runs a script command and sees the polycast-generated action behave identically to hand-written launcher code.
- **Current Friction:** Full emitter stack exists only in uncommitted working tree (23 dirty paths); main branch still has two emitters. No launch contract, no manual install verification log, and no Level A/B proof on live launcher surfaces.
- **Feature Opportunity:** Thin-shim `polycast run <id>` dispatcher so emitted artifacts stay tiny stubs. Deferred — see anti-goal; core cast path must land and prove first.
